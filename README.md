# FocusPilot 3.0

Полностью пересобранное Manifest V3 расширение.

## Установка
1. Распакуйте ZIP.
2. Откройте `chrome://extensions/`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение».
5. Выберите папку `FocusPilot_v3`.

## Возможности
- Smart New Tab
- Задачи
- Заметки
- Read Later
- Pomodoro
- Digital Shield: домены и конкретные URL-пути
- Статистика посещений
- Время на сайтах
- Heatmap фокуса
- Command Palette
- Быстрый захват страницы
- Тема
- Экспорт/импорт

## Блокировка
`youtube.com` — весь домен и поддомены.
`https://youtube.com/shorts` — конкретный путь `/shorts`.
